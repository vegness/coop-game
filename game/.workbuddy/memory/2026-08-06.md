# 2026-08-06

## 项目初次了解：Chicken_Co-op（鸡鸡大营救）
- Godot 4.6 纯 GDScript 项目，2D 像素风多人合作闯关游戏，版本 0.1.0，1280x720，pixel snap + nearest filter。
- 核心机制：鸡下蛋二段跳反冲（egg recoil）+ 滑翔（glide）+ 啄击（peck）；蛋可作为平台/被啄击推动。
- 7 种鸡子类（各配对应蛋）：bomb 炸弹 / heavy 重蛋 / bouncy 弹跳 / ice 冰 / sticky 粘性 / ghost 幽灵（穿墙）/ infinite 无限。
- 机关：PressurePlate 压力板、MovingPlatform 移动平台、WindZone 风区、Door 门、ExplodableWall 可破坏墙。基类 MechanismBase 有 IDLE/ACTIVATED/DEACTIVATED 状态机。
- 收集物：GoldenEgg 金蛋、Feather 羽毛（CollectibleBase）。
- 游戏流程：MainMenu → Lobby（联机大厅）→ 关卡（计划 8 关，目前仅有 TestLevel.tscn 测试关）。GameManager 支持单人教程/多人合作两种模式。
- 网络：NetworkManager（非 AutoLoad，Lobby 实例化）ENet 主机/客户端，端口 9999，最多 4 人；PlayerSync 做玩家同步。
- AutoLoad 单例：GameManager（流程/存档 user://save_data.cfg）、AudioManager、EventBus（事件总线）。
- 资源：res/pic 为 AI 参考图；res/jump|run|stop 为 Aseprite 逐帧动画源；addons/AsepriteWizard 为精灵导入插件。
- 完成度：原型阶段。玩家/机关/关卡框架齐全，但正式关卡未建，视觉大量为纯色占位，动画仅几帧。

- **新增 player/ChickPlayer.gd**（extends ChickenBase，重写 _create_egg 返回 null）。
- **scenes/chick.tscn 重构**：删误挂的 CollectibleBase Area2D；根挂 ChickPlayer.gd；加 CollisionShape2D(24x36, pos(0,6))；AnimatedSprite2D scale=0.08（帧图 640x640 过大）。

## 手感调整：降低跳跃高度
- ChickenBase.gd：jump_velocity -420→-360（一段跳实测 90px→69px）；egg_recoil_force -380→-320（二段跳≈52px）。
- 平台随新跳跃能力下调：Level_01 Platform1 y 480→599（离地约 65px，一段跳可上）。
- 实测方法：临时 SceneTree 脚本 + Input.parse_input_event(InputEventAction) 模拟按 Space，记录 min_y 算高度；Bash heredoc 写入临时脚本（Write 工具在此环境有文件同步问题，临时脚本须用 Bash cat 写）。

## 修复：滑翔不再"飞很高"（下蛋后仅缓降）
- 根因：下蛋反冲 vy=-320 后立即进滑翔，滑翔重力仅 150，导致继续上升 341px。
- 修复：ChickenBase._handle_glide_input 滑翔启动加条件 `velocity.y >= 0.0`（上升结束后才允许滑翔）→ 上升只来自一段跳(69px)/下蛋反冲(55px)，滑翔阶段全程 vy>=0 缓降。
- 实测 PASS：下蛋后上升 54.9px；滑翔 136 帧内 min_vy=+6.7（全程下降，最大落速 80）。
