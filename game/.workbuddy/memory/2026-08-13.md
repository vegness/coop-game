# 2026-08-13 工作日志

## 修复：LevelClear 点击结算页报 "Cannot call get_children on a null value"

### 根因
LevelClear.gd `_was_button_clicked()` 里节点路径写错：按钮实际在 `$Dialog/Inner/Buttons`（弹窗有 Inner 嵌套层），写成 `$Dialog/Buttons` → null.get_children() 报错。只在点击结算画面（_input → _was_button_clicked）触发。

### 修复
路径改为 `$Dialog/Inner/Buttons.get_children()`。已全查 LevelClear.gd 所有 `$Dialog/` 路径：其余（Inner/Buttons/*、Inner/Data/*、Inner/Stars）均正确。

### 验证
临时脚本调 `_was_button_clicked()` 不再报错（on_button=false，弹窗外点击正常判定）+ 关卡 200 帧无错 ✓

## 修复：机关门落下压死鸡（鸡被挤穿地面卡死）

### bug
门升起时鸡走进门正下方空位；trigger 释放门落下，实心门体把鸡挤穿地面 → 卡死无法操作。

### 修复（door.tscn + door.gd）
1. **door.tscn**：新增 `CrushArea`（Area2D，collision_mask=2，CollisionShape2D 比门碰撞体略高 `Rect_crush (2,10)` vs 门 (2,8)）——比门体向下多延伸约 60px（实例 scale 30），覆盖"鸡被挤到地面下"的区域，随门一起移动。
2. **door.gd**：
   - `_on_crush_body_entered`：鸡与门体重叠 → `revive(last_landed_position)` + `EventBus.player_fell_off`（与掉坑/尖刺一致），仅 authority 端处理。
   - **防死循环**：`_crush_immunity` 字典（chicken → 免疫到期时间，默认 0.8s），复活后短时间不再判死；且 `_get_respawn_pos` 若 last_landed_position 在门正下方（|x| < 半宽+14），水平偏移到门旁（半宽+24）——否则复活点在门下会无限"压死→复活→压死"。
   - 新增 `_compute_half_width()`（门全局半宽）。

### 验证
- 临时场景：门 start_open 抬起中心 380，鸡站门正下方 (0,632)；`door.deactivate()` 门落回 536 → 鸡复活到 (54, 632)（门右侧偏移），y 正常不再卡地下 ✓
- import + 关卡 200 帧无错误 ✓

### 与掉坑/尖刺逻辑的关系
统一模式：`body is ChickenBase → is_multiplayer_authority 检查 → revive(last_landed_position / spawn_position 兜底) → EventBus.player_fell_off`。区别只在触发源（y 超界 / 尖刺 Area / 门体 CrushArea）。**门多了一步"复活点避开门下区域"的防死循环处理**（掉落/尖刺的复活点天然不在触发区）。
