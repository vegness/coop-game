# 2026-08-24 工作日志

## 修复：多人模式退出后，单人模式按 K 不下蛋

**症状**：主菜单 → 多人（进 Lobby 或创建房间）→ 退出回主菜单 → 单人 → 进关卡，按 K 蛋不出现；纯单机开局下蛋正常。

**根因**（headless 诊断脚本 `tools/diag_egg.gd/.tscn` 复现，`DIAG_MODE=A/B/C` 环境变量切换）：
- `MultiplayerManager.disconnect_network()` 把 `multiplayer.multiplayer_peer = null`。
- Godot 4.6 中 peer=null 时 `multiplayer.get_unique_id()` 返回 **0**（且每次调用报 "No multiplayer peer is assigned"），而关卡内节点（MultiplayerSpawner 等）authority 为 **1**。
- `spawner.is_multiplayer_authority()` 恒 false → `MultiplayerSpawner.spawn()` 硬性条件失败返回 nullptr → 蛋既不生成也无 fallback（`_spawn_egg` 走 spawner 分支后直接 return）。
- 附带残留：`ENetBackend._is_host` 未清，退出后 `MultiplayerManager.is_server()` 仍为 true。

**修复**（4 个文件）：
1. `network/backends/network_backend.gd`：新增虚方法 `reset()`（清 `_is_host`）。
2. `network/backends/enet_backend.gd`：实现 `reset()`（清 `_peer` + `_is_host`）。
3. `network/backends/steam_backend.gd`：实现 `reset()`（清 `_steam_peer` + `_lobby_id` + `_is_host`）。
4. `autoload/multiplayer_manager.gd`：`disconnect_network()` 改为 `multiplayer.multiplayer_peer = OfflineMultiplayerPeer.new()`（恢复单机默认 peer，unique_id=1 与节点 authority 匹配），并调用 `backend.reset()`。

**验证**：A/B/C 三模式 headless 回归全部"蛋正常生成"（egg count 1→2）；`--import` 全量编译通过；主菜单冒烟通过。新增工具 `tools/diag_egg.gd/.tscn`（`DIAG_MODE=A|B|C` 环境变量）可复跑回归。

**顺带发现（未处理）**：`res/res/chick/` 各颜色动画帧 png UID 重复警告（复制文件所致），不影响功能，后续可统一重新生成 .uid。

## 联机解耦审查与补全（依据 doc/联机解耦开发指导文档.md）

**审查结论**：三层架构基本合规（is_server/is_network_connected/get_my_id 全走 MultiplayerManager；无 rpc_id(1)、无 multiplayer.is_server()、无 peer_id==1 硬编码权限判断；is_multiplayer_authority() 仅用于物理权限）。发现 5 处真实耦合点并修复：

1. `player/ChickenBase.gd` `_is_network_client()`：原直接读 `multiplayer.multiplayer_peer.get_connection_status()` → 改为 `MultiplayerManager.is_network_connected()`（语义等价，后端无关）。
2. `MultiplayerManager` 新增 `get_peers() -> Array[int]` 封装（未连接返回空数组）。
3. `levels/LevelBase.gd` / `ui/Lobby.gd`(×2) / `ui/character_select/CharacterSelect.gd`：`multiplayer.get_peers()` → `MultiplayerManager.get_peers()`。
4. 后端新增"房主 id"概念：`NetworkBackend._host_peer_id` + `get_host_peer_id()`（ENet create/join 成功时置 1；基类 reset() 清零）；`MultiplayerManager.is_host_peer(pid)` 封装。
5. `CharacterSelect.gd` 两处 `pid == 1` 判断房主 → `MultiplayerManager.is_host_peer(pid)`（文档 7.6 禁止硬编码，Steam 下失效）。

**验证**：`--import` 编译通过；diag_egg A/B/C 三模式下蛋正常；主菜单/Lobby/选角页冒烟通过；新增 `tools/diag_host_level.gd/.tscn` 验证真实 ENet 主机进关卡（get_peers=[]、is_host_peer(1)=true、players=1、下蛋正常、就绪握手链路完整——测试脚本 current_scene 赋值时序导致 play_ready 初始 false，手动触发 `_on_network_level_ready()` 后 true，非回归）。

**约定**：游戏逻辑层（player/levels/ui/mechanisms/collectibles）禁止直接 `multiplayer.xxx` 原生调用与 `pid==1` 判断房主，一律走 MultiplayerManager 封装。
