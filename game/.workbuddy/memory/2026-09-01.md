## 🪲 Aseprite MCP 两个坑（重要，联机排查/像素绘制必读）
1. **中文路径乱码**：含非 ASCII（如 `我的桌面`）的路径传给 aseprite MCP 会被转成 GBK 乱码报 File not found。规避：先复制到纯 ASCII 临时目录（如 C:\Users\50416\AppData\Local\Temp\ase_jungle）操作，完成后 bash 拷回项目。
2. **绘制/预览工具 frame bug**：create_canvas/add_layer/rename_layer/export 正常，但 draw_pixels/draw_grid/draw_shape/preview 全部报 "frame 1 out of range: sprite has 1 frame(s)"（服务端 Lua 对 1 帧精灵的帧索引 bug，frame=0 又被 1-based 校验拒绝）。
   **可靠绕过方案**：用 Aseprite CLI 直接跑 Lua 脚本 —— `E:\Aseprite\aseprite.exe -b --script xxx.lua`（Aseprite 路径来自 ~/.workbuddy/mcp.json 的 ASEPRITE_BIN）。脚本内 `Sprite(w,h,ColorMode.RGB)` + Image:drawPixel 程序化绘制，最后 saveAs(.aseprite) + saveCopyAs(.png)。比逐像素 MCP 调用更快更可控，建议地图类绘制一律走这条链路。
