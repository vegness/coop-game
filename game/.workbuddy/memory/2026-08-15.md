### 踩坑/要点
- **@export Node 引用在 tscn 用 `prop = NodePath(...)` 会解析成 nil** → 用 `@export var prop: NodePath` + `_ready` 里 `get_node_or_null(prop)`。
- 测试给 MultiplayerSpawner（spawn_path=..）子节点加蛋必须显式命名（`egg.name = "X_N"`），否则报 "Unable to auto-spawn node with reserved name @RigidBody2D@N"。
- 蛋重量=0.5 是全局机制 → 第一关按钮 require 必须调 0.5（否则蛋压不住门，破坏第一关玩法）。
- InfiniteChicken 走 `forced_chicken_type`，LevelBase 的 `set_chicken_color` 检查（has_method）跳过 → 纯色占位，不报错。
- 多人 P3 救援平台几何可达性未精调（对岸玩家跳 y=250 的 P3 够不着），等用户按 level2.png 调地图时一起处理。
