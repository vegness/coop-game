## 暂停菜单 Bug 修复（继续游戏无反应）
- 根因：`get_tree().paused = true` 后整个场景树停止处理输入，PauseMenu 默认 INHERIT 也暂停 → 按钮点击无效。
- 修复：HUD.gd `pause_menu.process_mode = Node.PROCESS_MODE_WHEN_PAUSED`。
- 新增功能：暂停菜单加「重新开始」(RestartBtn → GameManager.restart_level) 与「返回主菜单」(MenuBtn → GameManager.return_to_main_menu)；GameManager.restart_level/return_to_main_menu 增加 `get_tree().paused = false`（否则新场景卡暂停）。
- 验证：临时 autoload 注入 project.godot（TestPause）跑完整流程 8 项全 PASS（暂停/继续/重开/回菜单、scene=Level01/MainMenu）；验证脚本 process_mode 需 ALWAYS 才能在暂停时继续跑。验证后已恢复 project.godot、删除临时脚本。
