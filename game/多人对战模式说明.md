# 🐔 Chicken Co-op 多人对战模式说明

> 面向玩家的游戏说明，同时标注当前项目实现进度（方便开发对照）。
> 引擎：Godot 4.6.1 ｜ 类型：2D 像素风多人合作闯关 / 多人对战 ｜ 人数：1-4 人联机
> 参考设计：`doc/多人模式与对战开发文档.md`、`doc/框架.md`

---

## 一、游戏总览

玩家扮演一只会"下蛋反冲"的小鸡：空中按 Space 下蛋，蛋会给你一个向上反冲力，还能作为物理实体与场景互动。基于这套核心机制，游戏分两大模式：

| 模式 | 定位 | 说明 |
| ---- | ---- | ---- |
| **单人硬行** | 单机闯关 | 角色选择 → 选关 → 闯关解谜（教程向） |
| **多人模式** | 联机游玩 | 联机大厅组队后，可选择**多人闯关**（合作）或**多人对战**（竞技） |

多人对战（MULTI_VS）就是本说明的主角：在同一个"下蛋 + 蛋交互 + 机关"物理系统上做轻量竞技，**共用同一套小鸡 / 蛋 / 机关体系**，不引入新物理规则。

## 二、多人对战有哪些模式

多人对战入口下共有 **7 个玩法**（6 种单玩法 + 1 种混合模式）：

| # | 玩法 | 一句话规则 | 胜利条件 |
| - | ---- | ---------- | -------- |
| 1 | 🥚 **蛋球赛** | 下蛋并把蛋踢进对方球门 | 先得 3 球，或限时内得分多者胜 |
| 2 | 👋 **挤出局** | 把对手挤出屏幕视野 | 最后留在场上的玩家胜 |
| 3 | 🏁 **竞速赛** | 全员同场计时跑图 | 先到终点排名靠前，按名次给分 |
| 4 | 🐣 **孵化赛** | 比谁孵化的蛋多，可踩碎对方蛋 | 限时内孵化数最多者胜 |
| 5 | 🌾 **啄米地鼠** | 一人啄人，其余探头吃米 | 啄手淘汰全部对手 / 存活者吃米得分最高 |
| 6 | 🎭 **真假小鸡** | 捉捕者 vs 模仿者，混在人机里防被发现 | 捉捕者找出全部模仿者 / 模仿者撑到时间结束 |
| 7 | 🎲 **混合模式** | 选 ≥2 种玩法按轮次轮换 | 各轮积分累加，总积分最高者胜 |

> 每个玩法都有专属主题色（糖果色板）和一句话简介，在对战玩法选择界面轮播展示。

## 三、怎么选择：完整流程

### 3.1 选择链路

```
主菜单
 ├─ [单人硬行] ────────────────► 角色选择 → 选关 → 闯关
 └─ [多人模式]
      └─► 联机大厅 Lobby
           ├─ 创建房间（我是主机）
           └─ 输入 IP 加入（我是客机）
                │ 连接成功
                ▼
        多人模式选择 ModeSelect
         ├─ [多人闯关] ────────► 角色选择 → 合作关卡
         └─ [多人对战] ────────► 对战玩法选择 BattleModeSelect
                                   ├─ ◀ ▶ 轮播浏览 6 种玩法 → 点击玩法名开始
                                   ├─ [混合模式] → 勾选 ≥2 种玩法 → 确认开始
                                   └─ [返回] → 回到多人模式选择
```

### 3.2 各环节怎么操作

| 环节 | 界面 | 操作方式 |
| ---- | ---- | -------- |
| ① 主菜单 | MainMenu | 点 **多人模式** 进入联机大厅 |
| ② 联机大厅 | Lobby | **创建房间**（自己当主机）或 **输入主机 IP 加入**（当客机）；列表显示在线玩家；可返回主菜单 |
| ③ 多人模式选择 | ModeSelect | 点 **多人对战**（多人闯关则走合作链路） |
| ④ 对战玩法选择 | BattleModeSelect | 用 **◀ ▶ 箭头**左右循环浏览玩法（带预览图/占位色 + 一句话规则）；点 **玩法名按钮** 开始；或点 **混合模式** 弹出勾选面板，勾选 ≥2 种玩法后确认 |

### 3.3 谁来决定选哪个玩法（重要）

- **只有主机能选择并开始玩法**；客机的开始/混合/返回按钮是禁用的，只显示"等待主机选择玩法……"。
- 客机仍可用 ◀ ▶ 箭头**自由浏览玩法预览**（无副作用）。
- 主机选定后，通过 RPC 广播**全端同步**进入玩法场景，不会出现各端玩不同玩法的情况。
- 混合模式面板同样是主机操作：勾选数量 **少于 2 种会提示"至少选择 2 种玩法"**，无法开始。

### 3.4 断线兜底

任意界面（大厅 / 模式选择 / 玩法选择 / 对战中）主机掉线，全端自动弹遮罩返回主菜单，无需手动处理。

## 四、玩法详细介绍

### 4.1 蛋球赛（EggBall）🏃🥚

- **场地**：对称球场，左右各一个球门，平台/机关做障碍
- **怎么玩**：下蛋生成"球蛋"（特殊蛋，不吃碎蛋/孵化逻辑），用身体碰撞、下蛋反冲、E 键啄击把蛋撞进对方球门
- **细节**：蛋被踢出界外时由主机复位到中场
- **胜利**：先得 3 球；或限时 3 分钟得分多者胜

### 4.2 挤出局（KnockOut）💥

- **场地**：悬浮平台竞技场，四周无墙
- **怎么玩**：把对手挤下平台——身体碰撞、蛋反冲、蛋击退都行；被挤下屏幕即**淘汰且不复活**，直到只剩最后 1 人
- **胜利**：最后留在场上的玩家胜
- **提示**：这是唯一"掉场即淘汰"的玩法，其他玩法掉坑后都会复活

### 4.3 竞速赛（Race）🏁

- **场地**：优先复用闯关关卡子集（如 level_01 / 02），全员同场起跑
- **怎么玩**：从起点出发一路跑酷，允许互相踩蛋、推挤、使绊子
- **胜利**：按到达终点顺序给分——第 1 名 5 分、第 2 名 3 分……（混合模式中这些分累加到总榜）

### 4.4 孵化赛（HatchRace）🐣

- **怎么玩**：下蛋后蛋**不碎**，进入孵化倒计时（约 5 秒），到期孵出小鸡蛋计 1 分；**踩在对方蛋上可以把蛋踩碎**，让对方白忙一场
- **胜利**：限时 60 秒内孵化数最多者胜

### 4.5 啄米地鼠（PeckMole）🌾

- **怎么玩**：每轮 1 名玩家当"啄手"，其余玩家躲进掩体，**按键探头**吃随机出现在掩体上方的米；啄手靠近并啄击，被啄中的玩家淘汰
- **胜利**：啄手淘汰全部对手即赢；反之限时结束，**存活且吃米最多**的玩家赢
- **细节**：啄手角色由主机轮换，保证轮流当鬼

### 4.6 真假小鸡（ImposterChicken）🎭

- **怎么玩**：场上有 N 只**人机小鸡**按固定节奏做动作（跑/跳/啄……）；1 名捉捕者，其余玩家是**模仿者**，混在人机堆里、必须同步模仿人机的动作节奏来伪装；捉捕者按 E 啄击任意小鸡——啄到真玩家则该玩家淘汰，啄到人机没有惩罚但会暴露自己的位置
- **胜利**：捉捕者找出全部模仿者获胜；模仿者全部存活到倒计时结束（如 90 秒）则模仿者获胜
- **细节**：最高复杂度玩法，人机 AI + 动作混淆判定

### 4.7 混合模式（Mixed）🎲

- **怎么选**：在混合面板勾选 **≥2 种玩法**（最多 3 种，避免一局过长），确认后开始
- **怎么玩**：由轮次管理器（BattleDirector）每轮随机或按顺序抽取一种玩法加载，单轮时长按玩法预设（约 60~120 秒）；每轮结算按名次给分并累加
- **胜利**：全部轮次打完，**总积分最高**的玩家胜，展示总积分榜，可再来一局

## 五、通用规则（所有玩法适用）

| 规则 | 说明 |
| ---- | ---- |
| 🥚 **蛋击退** | 蛋命中对手只有击退、没有伤害（复用炸弹蛋击退逻辑，去掉伤害） |
| 🎨 **干扰蛋** | 部分玩法中，粘蛋/冰蛋/弹弹蛋可对对手造成减速 / 滑倒 / 弹飞 |
| 💀 **复活** | 除"挤出局"外，掉坑/出界 → 短延迟后在出生点复活 |
| ⏱️ **倒计时** | 一律主机权威计时并广播，不做各端本地计时 |

## 七、操作速查（小鸡基础操作）

| 按键 | 动作 |
| ---- | ---- |
| A / D | 左右移动 |
| Space（地面） | 挥翅一段跳 |
| Space（空中） | 下蛋二段跳（获得反冲） |
| Space（长按，已下蛋） | 滑翔缓慢下降 |
| E | 啄击 / 互动 |
