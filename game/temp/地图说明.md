# 多人对战风格背景图集（temp/）

> **本批为纯背景版**：只含氛围视觉（底色 / 远景剪影 / 地面带 / 装饰），
> **不含任何机制实体**（悬浮平台、球门、掩体、迷宫墙、起点旗、传送门等均已移除）。
> 机制组件按解耦原则后续在 `mechanisms/` 中做成独立可复用场景，按玩法拼装到关卡。

规格统一：1200×200 像素（×0.4 映射后 480×80），RGB，两层结构 `bg / decor`。
全部对应《多人对战模式说明.md》中的 7 种玩法场景，生成方式：Aseprite CLI + Lua 程序化绘制。

## 机制组件规划（后续在 mechanisms/ 单独实现，均从背景中解耦）

| 组件 | 用途 | 备注 |
| --- | --- | --- |
| `platform`（静态/悬浮平台） | 各模式通用 | 草顶/石台等皮肤可参数化 |
| `platform_rot`（旋转平台） | 挤出局 / 通用 | 绕轴心旋转的站踏平台 |
| `goal`（球门） | 蛋球赛 | 左右镜像 + 进球检测 Area |
| `pit`（断坑/陷阱口） | 竞速赛 | 配合复活逻辑 |
| `start_flag` / `end_portal` | 竞速赛 | 复用已有 portal 机制扩展 |
| `haystack`（草垛掩体） | 啄米地鼠 | 顶部开洞 = 探头点 |
| `bush`（草丛藏身点，**通用**，原 wheat） | 各模式通用 | 7 束圆润草团组成的密实藏身点；4 帧摆动 sprite（t^1.7 顶部摆幅大），小鸡进入 Sensor 时停摆 |
| `wall`（立墙/垂墙） | 真假小鸡 | 视线遮挡，静态碰撞 |
