🐔 Chicken Co-op - 游戏设计架构文档

引擎：Godot 4.3（项目实际运行于 4.6.1）
类型：2D 像素风多人合作闯关 / 多人对战
人数：1-4 人本地/在线联机
参考：Ultimate Chicken Horse + PICO PARK
核心机制：下蛋反作用力移动 + 关卡变异机制
模式：单人硬行 / 多人闯关（合作）/ 多人对战（规划中）

---

一、核心操作体系

1.1 操作映射

| 按键          | 触发条件     | 动作       | 状态流转                   |
| ------------- | ------------ | ---------- | -------------------------- |
| A/D           | 任意时刻     | 左右移动   | 保持当前状态               |
| Space（按下） | 地面         | 挥翅一段跳 | GROUND → JUMPING           |
| Space（按下） | 空中         | 下蛋二段跳 | JUMPING/FALLING → EGG_LAID |
| Space（长按） | 空中且已下蛋 | 滑翔       | EGG_LAID → GLIDING         |
| Space（松开） | 滑翔中       | 取消滑翔   | GLIDING → FALLING          |
| E             | 任意时刻     | 啄击互动   | 保持当前状态               |

1.2 状态机设计

GROUND (地面)
  └─ Space按下 ──► JUMPING (上升中)
                      └─ 到达顶点 ──► FALLING (下落中)
                                          └─ Space按下 ──► EGG_LAID (已下蛋)
                                                                └─ Space长按 ──► GLIDING (滑翔)
                                                                                    └─ Space松开 ──► FALLING
                                                                └─ 落地 ──► GROUND

核心约束：
- 空中按下 Space 只能是下蛋，不会产生一段跳
- 必须先完成下蛋，才能进入滑翔状态
- 每轮跳跃周期内只能下蛋一次，落地后重置
- 滑翔时保留水平控制，垂直下落速度受限

1.3 下蛋反冲系统

- 蛋生成于鸡身正下方偏后位置
- 鸡获得向上反冲力，同时保留大部分水平速度
- 反冲力方向可受当前移动方向影响（斜向飞行）
- 蛋作为物理实体存在于场景中，与机关/玩家/环境交互

2.2 扩展规范

新增 Chicken 子类时需提供：
- 子类名称与主题定位
- 重写创建蛋方法返回的 Egg 类型
- 特殊机制说明（如冷却时间、数量限制变化）
- 与现有系统的交互规则

新增 Egg 子类时需提供：
- 触发条件（落地/碰撞/定时/被啄/其他）
- 视觉效果描述
- 对玩家/环境/机关的影响范围
- 生命周期（持续时间/触发后销毁/永久存在）

三、关卡设计体系

3.1 关卡组成要素

| 要素     | 说明                                | 来源               |
| -------- | ----------------------------------- | ------------------ |
| 地形     | TileMap 构成的平台、墙壁、地面      | 内置素材库         |
| 机关     | 压力板、移动平台、风向区、传送门等  | MechanismBase 子类 |
| 鸡类型   | 本关强制使用的 Chicken 子类         | 关卡配置           |
| 目标     | 到达出口/收集物品/破坏目标/存活计时 | LevelBase 子类实现 |
| 蛋效果   | 由鸡类型决定，影响解谜方式          | Chicken-Egg 绑定   |
| 环境效果 | 重力变化、风向、水面、黑暗区域等    | 场景节点配置       |

3.2 主线关卡规划

| 章节 | 工厂主题   | 解锁鸡类型      | 核心教学点           | 弱剧情节点                 |
| ---- | ---------- | --------------- | -------------------- | -------------------------- |
| 1    | 炸弹工坊   | BombChicken     | 下蛋反冲 + 爆炸破坏  | 咕咕发现下蛋能飞，逃离农场 |
| 2    | 无限孵化室 | InfiniteChicken | 无限资源堆叠         | 遇到疯狂下蛋的母鸡         |
| 3    | 重力实验室 | HeavyChicken    | 重量与压力机关       | 农场主的重力实验失败产物   |
| 4    | 弹跳游乐场 | BouncyChicken   | 弹性利用与连锁反弹   | 废弃儿童乐园改造           |
| 5    | 冷冻储藏库 | IceChicken      | 临时平台搭建         | 阻止鸡蛋被冷冻运输         |
| 6    | 粘粘胶带厂 | StickyChicken   | 垂直攀爬与固定点     | 工业胶水泄漏变异           |
| 7    | 幽灵废弃厂 | GhostChicken    | 穿墙与相位解谜       | 老工厂的"闹鬼"传说         |
| 8    | 主控核心   | 全部混合        | 多能力配合与终极挑战 | 破坏打蛋机，营救蛋宝宝     |

3.3 关卡目标类型

- REACH_EXIT：到达指定出口区域
- COLLECT_EGGS：收集场景中的所有金蛋
- DESTROY_TARGET：破坏指定数量的目标物体
- SURVIVE：在时限内存活到达终点
- ESCORT：护送物体到达目标点

四、多人合作机制

4.1 强制配合设计

| 机制名称 | 说明                           | 触发条件       |
| -------- | ------------------------------ | -------------- |
| 蛋梯     | 蛋作为可站立平台               | 自然物理堆叠   |
| 连锁反冲 | A下蛋时B站在蛋上，B被弹飞      | 物理碰撞       |
| 重量机关 | 多人/重蛋同时压住多个压力板    | 压力板检测     |
| 蛋传递   | 啄击推动蛋，传递给队友         | E键啄击        |
| 救援机制 | 掉出地图变为毛球，队友啄击复活 | 掉落触发 + E键 |
| 滑翔接力 | 滑翔中的鸡可作为移动平台       | 物理碰撞       |
| 爆炸助推 | 炸弹蛋爆炸将队友炸向目标方向   | 爆炸范围检测   |

4.2 友军互动（欢乐来源）

- 炸弹爆炸纯击退、无伤害，可故意炸飞队友
- 无限蛋堆会造成地形阻碍，队友可能滑倒
- 冰蛋铺成的地面摩擦力极低，队友容易失控
- 弹弹蛋会将踩上去的队友弹射

五、弱剧情主线：蛋蛋大营救

5.1 世界观

邪恶农场主建造了"全自动打蛋机"，要将所有鸡蛋加工成食品。主角母鸡咕咕意外觉醒下蛋反冲能力，带领鸡群伙伴们闯入8座工厂，破坏机器，营救蛋宝宝。

5.2 叙事方式

| 方式     | 内容                           | 时长/规模 |
| -------- | ------------------------------ | --------- |
| 章节开场 | 像素动画：咕咕跑向工厂大门     | 3-5秒     |
| 关卡内   | 背景细节：海报、告示、机器残骸 | 静态贴图  |
| 过关画面 | 简笔画插图 + 一句话文案        | 2-3秒     |
| 全程     | 无对话、无文字剧情、纯视觉     | —         |

5.3 文案示例

- "咕咕发现，下蛋不仅能飞，还能炸东西……"
- "原来农场主把失败的实验都扔进了游乐场。"
- "这些蛋宝宝……不能再等了。"

六、系统架构关系图

6.1 游戏入口与模式选择流程（2026-08-26 修订）

```
游戏入口 (MainMenu)
    │
    ├── 单人硬行（单人模式）
    │       └── 角色选择 → 选关（LevelSelect）→ LevelBase
    │
    └── 多人模式
            ├── ① 多人联机大厅 (Lobby)
            │       └── IP 连接（创建房间 / 输入 IP 加入 / 玩家列表 / 返回）
            │               │
            │               └── ② 多人模式选择 (ModeSelect)
            │                       ├── 多人闯关（合作）→ 角色选择 → LevelBase
            │                       │
            │                       └── ③ 对战玩法选择 (BattleModeSelect)
            │                               ├── 蛋球赛（踢蛋进门）
            │                               ├── 挤出局（把对手挤下屏幕）
            │                               ├── 竞速赛（先到终点）
            │                               ├── 孵化赛（比谁孵化的蛋多）
            │                               ├── 啄米地鼠（啄人 vs 探头吃米）
            │                               ├── 真假小鸡（捉捕者 vs 模仿者）
            │                               ├── 更多玩法（开发中，占位）
            │                               └── 混合模式（≥2 种玩法轮换）
            │
            └── （连接断开 → 回主菜单，走 GameManager.return_to_main_menu）
```

流程说明：
- 主菜单入口按钮：**单人硬行**、**多人模式**（游戏模式入口），并保留原有**设置**、**退出游戏**按钮
- 多人模式点击后**先进联机大厅**：完成 IP 连接（创建房间 = 主机 / IP 加入 = 客机），连接成功后才允许进入模式选择
- 模式选择阶段新增 **ModeSelect 场景**：多人闯关（走既有合作链路）/ 多人对战（新玩法，见 6.2）
- 多人对战再下一层为 **BattleModeSelect 对战玩法选择**：6 种已规划玩法 + 开发中占位 + 混合模式
- **接口约束**：本流程只调整 UI 层流转（MainMenu / Lobby / ModeSelect / BattleModeSelect），GameManager / MultiplayerManager / LevelBase 等既有接口暂不修改；多人对战后续通过新增 GameMode 枚举与场景实现，不触碰既有闯关链路

6.2 多人对战模式（规划，2026-08-26 草案）

定位：在既有"下蛋反冲 + 蛋交互"物理玩法之上构建轻量竞技，与多人闯关共用同一套
Chicken/Egg/Mechanism 系统，不引入新物理体系。

| 玩法         | 规则一句话                     | 复杂度 |
| ------------ | ------------------------------ | ------ |
| 蛋球赛       | 下蛋并把蛋踢进对方球门         | 中     |
| 挤出局       | 把对手挤下屏幕视野（出界淘汰） | 低     |
| 竞速赛       | 全员同场计时跑图，先到终点者胜 | 低     |
| 孵化赛       | 下蛋后延迟孵化，可踩碎对方蛋，比孵化数 | 中 |
| 啄米地鼠     | 一人啄，其余探头吃米，被抓则淘汰 | 中   |
| 真假小鸡     | 捉捕者 vs 模仿者，模仿人机防被发现 | 高   |
| 混合模式     | 选 ≥2 种玩法按轮次轮换，总积分结算 | 中 |

通用设计：
- 交互：蛋可"踢给/砸向"对手造成击退（复用爆炸击退，无伤害）
- 地图：优先复用闯关关卡子集，后续新增对称竞技图
- 同步：与闯关完全一致（MultiplayerSynchronizer + RPC + Spawner）
- 实现路径：新增 GameMode.MULTI_VS + BattleBase（玩法基类）+ 独立结算 UI；
  各玩法作为 BattleBase 子场景，混合模式由轮次管理器顺序加载

详细设计与开发步骤见《多人模式与对战开发文档》。

七、预留模块：关卡编辑器（未来功能）

7.1 设计定位

- 玩家通过拖拽方式从素材库放置地形、机关、收集物

- 可设置通关目标与条件
