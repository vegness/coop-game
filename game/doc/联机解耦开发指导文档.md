# Chicken Co-op 联机解耦开发指导文档

> **版本**：v1.1  
> **引擎**：Godot 4.3  
> **目标**：游戏逻辑与网络后端完全解耦，支持 ENet（开发测试）与 Steam（正式环境）无缝切换

> **v1.1 修订说明**（2026-08-09）
> 1. 修正 `add_child(egg, true)` 虚构 API —— Godot 4 的 `Node.add_child()` 没有第二个参数，网络同步必须走 `MultiplayerSpawner`
> 2. 修正 `is_host()` 用 `get_peer_id() == 1` 判断 —— 仅 ENet 成立，Steam 下 unique_id 是 Steam ID 映射值，改为后端维护 `_is_host` 标志
> 3. 明确 ENet 仅限本地/局域网测试，公网联机走 Steam Relay
> 4. 补充"与现有项目适配"说明（不强制迁移目录结构）
> 5. 新增陷阱条目 7.6（主机判断）
> 6. 修正 `is_connected()` 覆盖 `Object` 原生方法（警告视为错误时编译失败），改名为 `is_network_connected()`

## 一、设计哲学

**核心原则**：游戏逻辑层只认识 Godot 原生的 `MultiplayerAPI`，不认识 ENet，也不认识 Steam。

| 层级 | 职责 | 是否可替换 |
|------|------|-----------|
| 游戏逻辑层 | 玩法、物理、状态同步、RPC 调用 | ❌ 唯一 |
| 网络抽象层 | 定义连接/断开/身份查询接口 | ❌ 唯一 |
| 网络实现层 | 具体的 `MultiplayerPeer` 创建与管理 | ✅ 可替换 |

**收益**：
- 开发期用 ENet 本地测试，无需 Steam 环境
- 集成期接入 Steam，游戏逻辑代码**零改动**
- 未来如需支持主机服务器（Dedicated Server），只需新增一个后端实现类

## 三、核心代码实现

### 3.1 抽象接口：NetworkBackend

> 路径：`res://network/backends/network_backend.gd`

所有网络后端必须继承此类，实现统一接口。

```gdscript
class_name NetworkBackend
extends RefCounted

## 创建主机（房间）
## @param max_players: 最大玩家数
## @return: Error 状态
func create_host(max_players: int) -> Error:
    push_error("[NetworkBackend] create_host() 未实现")
    return ERR_UNCONFIGURED

## 加入主机
## @param address: 对 ENet 是 IP:Port；对 Steam 是 Lobby ID 字符串
## @return: Error 状态
func join_host(address: String = "") -> Error:
    push_error("[NetworkBackend] join_host() 未实现")
    return ERR_UNCONFIGURED

## 获取本机 Peer ID
## 注意：仅 ENet 下 1=主机、>1=客机；Steam 下是 Steam ID 映射值，
##       绝对不能用来判断是否主机！
func get_peer_id() -> int:
    push_error("[NetworkBackend] get_peer_id() 未实现")

## 是否为主机

    pass

## 获取连接状态

    return MultiplayerPeer.CONNECTION_DISCONNECTED

## 获取后端名称（调试用）

    return "AbstractBackend"
```

### 3.2 ENet 实现：EnetBackend

> 路径：`res://network/backends/enet_backend.gd`

用于**开发期本地测试**，不依赖 Steam，支持同一台电脑多开。

```gdscript
class_name ENetBackend
extends NetworkBackend

var _peer: ENetMultiplayerPeer

func create_host(max_players: int) -> Error:
    _peer = ENetMultiplayerPeer.new()
    var err := _peer.create_server(7777, max_players)
    if err == OK:
        _is_host = true
        _inject_peer()
    else:
        push_error("[ENet] 创建服务器失败: %d" % err)
    return err

func join_host(address: String = "") -> Error:
    var ip := address if address != "" else "127.0.0.1"
    _peer = ENetMultiplayerPeer.new()
    var err := _peer.create_client(ip, 7777)
    if err == OK:
        _is_host = false
        _inject_peer()
    else:
        push_error("[ENet] 连接客户端失败: %d" % err)
    return err

func get_peer_id() -> int:
    if _peer:
        return _peer.get_unique_id()
    return 0

func disconnect_peer(peer_id: int) -> void:
    if _peer:
        _peer.disconnect_peer(peer_id)

func get_connection_status() -> MultiplayerPeer.ConnectionStatus:
    if _peer:
        return _peer.get_connection_status()
    return MultiplayerPeer.CONNECTION_DISCONNECTED

func get_backend_name() -> String:
    return "ENet"

## 将 peer 注入全局管理器
func _inject_peer() -> void:
    MultiplayerManager.set_peer(_peer)
```

### 3.3 Steam 实现：SteamBackend

> 路径：`res://network/backends/steam_backend.gd`

用于**正式环境**，依赖 GodotSteam 插件（GDExtension）。

```gdscript
class_name SteamBackend
extends NetworkBackend

var _steam_peer: SteamMultiplayerPeer
var _lobby_id: int = 0

# ── 创建主机 ──────────────────────────────

func create_host(max_players: int) -> Error:
    # 先创建 Steam Lobby，等待回调后再创建 P2P Host
    Steam.createLobby(Steam.LOBBY_TYPE_FRIENDS_ONLY, max_players)
    Steam.lobby_created.connect(_on_lobby_created, CONNECT_ONE_SHOT)
    return OK

func _on_lobby_created(result: int, new_lobby_id: int) -> void:
    if result != Steam.RESULT_OK:
        push_error("[Steam] Lobby 创建失败，结果码: %d" % result)
        return

    _lobby_id = new_lobby_id
    _steam_peer = SteamMultiplayerPeer.new()
    _is_host = true
    _steam_peer.create_host(0)  # Steam P2P 不需要显式端口
    _inject_peer()
    print("[Steam] Lobby 创建成功，ID: %d" % _lobby_id)

# ── 加入主机 ──────────────────────────────

func join_host(address: String = "") -> Error:
    var target_lobby := int(address) if address.is_valid_int() else 0
    if target_lobby == 0:
        push_error("[Steam] 加入失败：需要提供有效的 Lobby ID")
        return ERR_INVALID_PARAMETER

    Steam.joinLobby(target_lobby)
    Steam.lobby_joined.connect(_on_lobby_joined, CONNECT_ONE_SHOT)
    return OK

func _on_lobby_joined(new_lobby_id: int, _permissions: int, _locked: bool, response: int) -> void:
    if response != Steam.CHAT_ROOM_ENTER_RESPONSE_SUCCESS:
        push_error("[Steam] 加入 Lobby 失败，响应码: %d" % response)
        return

    _lobby_id = new_lobby_id
    var owner_id := Steam.getLobbyOwner(_lobby_id)

    _steam_peer = SteamMultiplayerPeer.new()
    _is_host = false
    _steam_peer.create_client(owner_id, 0)  # 连接到主机玩家的 Steam ID
    _inject_peer()
    print("[Steam] 已加入 Lobby %d，主机 Steam ID: %d" % [_lobby_id, owner_id])

# ── 通用方法 ──────────────────────────────

func get_peer_id() -> int:
    if _steam_peer:
        return _steam_peer.get_unique_id()
    return 0

func disconnect_peer(peer_id: int) -> void:
    if _steam_peer:
        _steam_peer.close_connection(peer_id, Steam.NET_CONNECTION_END_APP, "玩家断开")

func get_connection_status() -> MultiplayerPeer.ConnectionStatus:
    if _steam_peer:
        return _steam_peer.get_connection_status()
    return MultiplayerPeer.CONNECTION_DISCONNECTED

func get_backend_name() -> String:
    return "Steam"

func get_lobby_id() -> int:
    return _lobby_id

func _inject_peer() -> void:
    MultiplayerManager.set_peer(_steam_peer)
```

### 3.4 全局管理器：MultiplayerManager

> 路径：`res://autoload/multiplayer_manager.gd`  
> 设置：Project → Project Settings → Autoload → 添加此脚本

这是**游戏逻辑层唯一接触的网络入口**。

```gdscript
extends Node

# ═══════════════════════════════════════════
# 信号
# ═══════════════════════════════════════════

## 有玩家连接（包括自己连接成功时）
signal player_connected(peer_id: int)
## 有玩家断开
signal player_disconnected(peer_id: int)
## 与主机断开（客机专属）
signal server_disconnected
## 网络后端切换完成
signal backend_changed(backend_name: String)

# ═══════════════════════════════════════════
# 属性
# ═══════════════════════════════════════════

## 当前注入的网络后端
var backend: NetworkBackend:
    get:
        return _backend
    set(value):
        _backend = value
        backend_changed.emit(value.get_backend_name() if value else "None")

var _backend: NetworkBackend
var _current_peer: MultiplayerPeer

# ═══════════════════════════════════════════
# 生命周期
# ═══════════════════════════════════════════

func _ready() -> void:
    # 监听 Godot 原生多人事件
    multiplayer.peer_connected.connect(_on_peer_connected)
    multiplayer.peer_disconnected.connect(_on_peer_disconnected)
    multiplayer.server_disconnected.connect(_on_server_disconnected)
    multiplayer.connected_to_server.connect(_on_connected_to_server)

# ═══════════════════════════════════════════
# 后端注入（由具体实现类调用）
# ═══════════════════════════════════════════

## 设置当前 MultiplayerPeer（由 ENetBackend / SteamBackend 调用）
func set_peer(peer: MultiplayerPeer) -> void:
    _current_peer = peer
    multiplayer.multiplayer_peer = peer

## 手动切换网络后端（通常在主菜单初始化时调用）
func set_network_backend(new_backend: NetworkBackend) -> void:
    backend = new_backend
    print("[MultiplayerManager] 网络后端已切换为: %s" % backend.get_backend_name())

# ═══════════════════════════════════════════
# 游戏逻辑层 API（与后端无关）
# ═══════════════════════════════════════════

## 创建房间
func create_room(max_players: int = 4) -> Error:
    if backend == null:
        push_error("[MultiplayerManager] 未设置网络后端")
        return ERR_UNCONFIGURED
    return backend.create_host(max_players)

## 加入房间
## @param address: ENet 用 IP；Steam 用 Lobby ID 字符串
func join_room(address: String = "") -> Error:
    if backend == null:
        push_error("[MultiplayerManager] 未设置网络后端")
        return ERR_UNCONFIGURED
    return backend.join_host(address)

## 获取本机 Peer ID（1=主机，>1=客机，0=离线）
func get_my_id() -> int:
    if backend:
        return backend.get_peer_id()
    return 0

## 是否为主机
func is_server() -> bool:
    if backend:
        return backend.is_host()
    return false

## 是否已连接
## 注意：不能命名为 is_connected()，会覆盖 Object 原生方法（Godot 警告视为错误时编译失败）
func is_network_connected() -> bool:
    if backend:
        return backend.get_connection_status() == MultiplayerPeer.CONNECTION_CONNECTED
    return false

## 断开连接并清理
func disconnect_network() -> void:
    if _current_peer:
        _current_peer.close()
        _current_peer = null
    multiplayer.multiplayer_peer = null
    print("[MultiplayerManager] 网络已断开")

# ═══════════════════════════════════════════
# 内部事件转发
# ═══════════════════════════════════════════

func _on_peer_connected(peer_id: int) -> void:
    print("[MultiplayerManager] 玩家连接: %d" % peer_id)
    player_connected.emit(peer_id)

func _on_peer_disconnected(peer_id: int) -> void:
    print("[MultiplayerManager] 玩家断开: %d" % peer_id)
    player_disconnected.emit(peer_id)

func _on_server_disconnected() -> void:
    print("[MultiplayerManager] 与主机断开连接")
    server_disconnected.emit()

func _on_connected_to_server() -> void:
    print("[MultiplayerManager] 成功连接到服务器")
```

## 四、游戏逻辑层编写规范

### 4.1 原则清单

| ✅ 应该做 | ❌ 禁止做 |
|---------|----------|
| 使用 `@rpc` 注解进行远程调用 | 直接调用 `Steam.xxx()` 或 `ENet.xxx()` |
| 使用 `is_multiplayer_authority()` 判断权限 | 用 `MultiplayerManager.is_server()` 替代权威判定（物理权限 ≠ 主机身份） |
| 使用 `MultiplayerSpawner` 生成网络对象 | 手动 `add_child()` 后自己写同步代码 |
| 通过 `MultiplayerManager` 查询网络状态 | 在玩家控制器里判断后端类型 |
| 用 `multiplayer.get_unique_id()` 获取自身 ID | 硬编码玩家编号 |

### 4.2 玩家控制器示例

> 路径：`res://game/chicken/chicken_base.gd`

```gdscript
class_name ChickenBase
extends CharacterBody2D

@export var move_speed: float = 200.0
@export var jump_force: float = 300.0
@export var egg_recoil: float = 250.0

@onready var _sync: MultiplayerSynchronizer = $MultiplayerSynchronizer
@onready var _sprite: Sprite2D = $Sprite2D

# 状态机
enum State { GROUND, JUMPING, FALLING, EGG_LAID, GLIDING }
var _state: State = State.GROUND
var _has_egg_laid: bool = false

func _ready() -> void:
    # 只有权威端（本机控制）才处理输入
    if not is_multiplayer_authority():
        return

    # 非权威端：关闭本地物理模拟，只接收同步数据
    set_physics_process(is_multiplayer_authority())

func _physics_process(_delta: float) -> void:
    if not is_multiplayer_authority():
        return

    # ── 移动 ──
    var input := Input.get_axis("move_left", "move_right")
    velocity.x = input * move_speed

    # ── 跳跃 / 下蛋 / 滑翔 ──
    if Input.is_action_just_pressed("jump"):
        match _state:
            State.GROUND:
                _rpc_jump()
            State.JUMPING, State.FALLING:
                if not _has_egg_laid:
                    _rpc_lay_egg()
            State.EGG_LAID:
                _rpc_start_glide()

    if Input.is_action_just_released("jump") and _state == State.GLIDING:
        _rpc_stop_glide()

    # ── 啄击互动 ──
    if Input.is_action_just_pressed("interact"):
        _rpc_peck()

    move_and_slide()

# ═══════════════════════════════════════════
# RPC 方法（网络层无关，Godot 自动路由）
# ═══════════════════════════════════════════

@rpc("any_peer", "call_local")
func _rpc_jump() -> void:
    velocity.y = -jump_force
    _state = State.JUMPING
    _sprite.play("jump")

@rpc("any_peer", "call_local")
func _rpc_lay_egg() -> void:
    _has_egg_laid = true
    _state = State.EGG_LAID

    # 反冲力
    velocity.y = -egg_recoil

    # 生成蛋：通过关卡场景中的 MultiplayerSpawner 同步到所有客户端
    # 注意：Node.add_child() 没有第二个参数！网络同步必须走 MultiplayerSpawner
    var spawner: MultiplayerSpawner = get_tree().current_scene.get_node("Eggs/MultiplayerSpawner")
    spawner.spawn({
        "egg_scene": "res://game/egg/egg_base.tscn",
        "position": global_position + Vector2(0, 16),
        "owner_id": multiplayer.get_unique_id(),
    })

    _sprite.play("lay_egg")

@rpc("any_peer", "call_local")
func _rpc_start_glide() -> void:
    _state = State.GLIDING
    velocity.y = clamp(velocity.y, -50, 50)  # 限制下落速度
    _sprite.play("glide")

@rpc("any_peer", "call_local")
func _rpc_stop_glide() -> void:
    _state = State.FALLING
    _sprite.play("fall")

@rpc("any_peer", "call_local")
func _rpc_peck() -> void:
    _sprite.play("peck")
    # 啄击检测逻辑...

# ═══════════════════════════════════════════
# 状态重置（落地时）
# ═══════════════════════════════════════════

func _on_landed() -> void:
    _state = State.GROUND
    _has_egg_laid = false
    _sprite.play("idle")
```

### 4.3 网络对象生成规范

**必须使用 `MultiplayerSpawner`**，不要手动 `add_child` 后不做任何同步：

```gdscript
# 错误 ❌
var egg = preload("res://egg.tscn").instantiate()
get_parent().add_child(egg)  # 其他客户端看不到！

# ⚠️ 特别提醒：Node.add_child() 没有第二个参数！
# 网上有些教程写 add_child(node, true) 表示"网络同步"，这是虚构的 API，Godot 4 会直接报错。
```

**正确做法（一）：`MultiplayerSpawner.spawn()`（推荐）**

场景中放置 `MultiplayerSpawner` 并绑定自定义生成函数：

```
LevelScene
├── TileMap
├── Players
│   └── MultiplayerSpawner        ← spawn_path = Players
│       └── _spawnable_scenes: [chicken_base.tscn]
├── Eggs
│   └── MultiplayerSpawner        ← spawn_path = Eggs
│       └── _spawnable_scenes: [egg_base.tscn]
└── Mechanisms
    └── ...
```

在 MultiplayerSpawner 的脚本里实现 `spawn_function`（由 spawner 在各端自动调用）：

```gdscript
# Eggs/MultiplayerSpawner 的 spawn 自定义函数
func _egg_spawn(spawn_data: Dictionary) -> Node:
    var egg: Node = (load(spawn_data["egg_scene"]) as PackedScene).instantiate()
    egg.position = spawn_data["position"]
    egg.chicken_owner_id = spawn_data["owner_id"]
    return egg

# 业务代码中调用（各端会自动执行 _egg_spawn 并生成蛋）
$Eggs/MultiplayerSpawner.spawn({
    "egg_scene": "res://game/egg/egg_base.tscn",
    "position": global_position + Vector2(0, 16),
    "owner_id": multiplayer.get_unique_id(),
})
```

> 注意：`_spawnable_scenes`（带 spawner 的 `spawn` 自定义函数）二选一即可；
> 使用自定义 `spawn_function` 时，spawner 会在所有端调用它并 `add_child` 生成的节点。

**正确做法（二）：在 spawn_path 指向的节点下 `add_child`（spawner 自动广播）**

```gdscript
# MultiplayerSpawner.spawn_path 指向 $Eggs，在 $Eggs 下 add_child 会被 spawner 自动同步
$Eggs.add_child(egg)
```

### 5.2 大厅 UI 适配

```gdscript
extends Control
```

## 七、常见陷阱与解决方案

### 7.1 同一个 Steam 账号无法多开测试

**现象**：一台电脑开两个客户端，第二个无法连接或行为异常。  
**原因**：Steam P2P 以 Steam ID 作为唯一标识，同一账号 ID 相同导致包路由失败。  
**解决**：必须使用两个不同的 Steam 账号（建议注册小号 + Dev Comp Key 激活）。

### 7.2 `call_local` 与 `call_remote` 混淆

**现象**：主机执行动作，客机看不到；或者客机执行，主机看到两次。  
**原因**：RPC 模式选择错误。  
**规范**：
- `@rpc("any_peer", "call_local")`：本地执行 + 广播给所有人（适合视觉效果）
- `@rpc("authority", "call_remote")`：仅权威端执行，同步给客机（适合状态变更）
- **不要**在客机调用 `@rpc("any_peer")` 但不带 `call_local`，否则本地不执行。

### 7.3 物理不同步

**现象**：蛋的位置在主机和客机画面不一致。  
**原因**：Godot 的物理模拟不是确定性（deterministic）的，各客户端独立计算会漂移。  
**解决**：
- 动态物体（蛋、玩家）用 `MultiplayerSynchronizer` 同步 `position/velocity`
- 静态/机关物体由主机权威控制，客机只接收状态
- 对快速移动对象开启插值（interpolate）

### 7.4 主机掉线导致全房崩溃

**现象**：主机退出，所有客机断开，游戏结束。  
**原因**：P2P 主机-客机架构的固有问题。  
**解决**：实现 **Host Migration（主机迁移）**：

```gdscript
# 在 MultiplayerManager 中
func _on_server_disconnected() -> void:
    # 客机检测到主机掉线
    if not is_server():
        # 选举新的主机（通常选 peer_id 最小的）
        var new_host_id := _elect_new_host()
        if new_host_id == get_my_id():
            promote_to_host()

func promote_to_host() -> void:
    # 新主机重新创建 peer，其他客机重新连接
    # 这是一个复杂功能，建议 MVP 阶段先不做，标记为 TODO
    pass
```

> **MVP 建议**：先不实现主机迁移，掉线直接回大厅。上线后再迭代。

### 7.5 Steam 初始化失败

**现象**：`Steam.steamInit()` 返回 status != 1。  
**排查**：
1. 确认 `steam_appid.txt` 存在且内容为正确的 App ID
2. 确认游戏是通过 Steam 客户端启动（或 steam_appid.txt 在可执行文件同级目录）
3. 确认 GodotSteam 插件版本与 Godot 4.3 匹配
4. 查看 Godot 输出面板的详细错误信息

### 7.6 用 `peer_id == 1` 判断主机在 Steam 下失效

**现象**：切换到 Steam 后端后，`is_host()` 恒为 false，主机端执行了客机逻辑。  
**原因**：ENet 的 unique_id 是自增整数（1=主机），但 Steam P2P 的 unique_id 是 Steam ID
映射值，**不是 1**。所有依赖 `get_peer_id() == 1` 的代码在 Steam 后端都会出错。  
**解决**：后端在 `create_host()` 成功时置 `_is_host = true`、`join_host()` 成功时置
`_is_host = false`，`is_host()` 只读该标志（见 3.1）。游戏逻辑层用
`MultiplayerManager.is_server()`，永远不要自己判断 peer_id。
